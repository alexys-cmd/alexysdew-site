# alexysdew.com

Alexys Dew's portfolio site. Plain HTML/CSS/JS, hosted free on GitHub Pages.

## Quick edits (in GitHub: open a file → pencil icon → edit → "Commit changes")
- **Blog posts:** added automatically every morning from Medium (`js/posts.js`). To run it right away: Actions tab → "Sync Medium posts" → Run workflow.
- **Portfolio projects:** `js/projects.js`. Instructions are at the top of the file.
- **Resume PDF:** upload a new file named `Alexys-Dew-Resume.pdf` into `files/` (same name replaces the old one).
- **Page text:** the `.html` file for that page (index = Home).
- **Images:** upload into `images/` or `images/work/` (WebP or JPG, about 800–1600px wide).

Changes go live about a minute after you commit.
